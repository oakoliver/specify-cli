# Changelog

## 2.1.0 (2026-11-02): sync with spec-kit 1.2.5

Brings the port from upstream spec-kit **1.0.12** to **1.2.5** (releases 1.0.13, 1.1.0 to 1.1.3 and 1.2.0 to 1.2.5).

Every upstream pull request in those releases is listed below with what happened to it:

- **Ported**: same behaviour as upstream, with upstream's tests ported where they exist.
- **Adapted**: same behaviour, implemented differently because the port runs on Node or Bun and has no runtime dependencies.
- **Partly ported**: the parts that apply are in; the rest is listed as not ported, with the reason.
- **Not ported**: left out, with the reason.
- **Vendored**: a bundled template, script, extension, preset, workflow or catalog file copied verbatim into `core_pack/`.
- **Equivalent**: the port already behaved this way.

How parity was checked:

- `specify init` produces the same files, contents and file modes as upstream 1.2.5 in 14 configurations: claude, claude with `--no-model-invocation`, copilot with `--script ps`, codex with `--script py`, gemini, generic, none, mcode, vibe with `--no-model-invocation`, `--extension git`, `--extension github`, opencode with `--preset lean`, junie and docker-agent.
- The integration, registrar, workflow-expression, YAML and MCP fixtures are generated by running upstream Python. The generators are in `tests/fixtures/generate/`.
- Tests went from 3,121 to 4,331.

### Breaking changes

None in the command-line interface: no flag or command was removed. These behaviours are stricter, as upstream made them:

- A project command now refuses a symlinked `.specify` directory, a symlinked or malformed `.specify/init-options.json`, or a non-boolean `allow_symlinks` (#4934).
- `.extensionignore` rejects a bare `!` and reversed character ranges such as `[z-a]`. A hook `command` must be a non-blank string, and an explicit `null` `matcher` or `timeout` is an error (#5131, #5146, #5133).
- Shell workflow steps whose output is not valid UTF-8 now fail (#5064).
- The SHAI integration no longer dispatches workflow steps (#4791).
- Pressing Ctrl+C at a workflow gate pauses the run instead of rejecting it (#4529).
- Workflow `state.json` gains `inputs` and an `execution` tree. A run saved by 2.0.x resumes once in legacy mode and is then converted (#4764).

## 2.0.0 (2026-09-27): sync with spec-kit 1.0.12

Brought the port from spec-kit 0.7.0 to 1.0.12: integrations replace agents (41 integrations), new `workflow`, `bundle`, `artifact`, `event` and `self` commands, `extension.yml` / `preset.yml` manifests, and the 1.0.12 templates and scripts. Breaking, as upstream 1.0 was: the `--ai`, `--ai-commands-dir`, `--ai-skills` and `--no-git` init flags are gone.
